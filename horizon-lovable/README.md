# Horizon Fest 2 - Track Drawer & 3D Racer

A high-octane 3D arcade racing simulator and custom track drawer built with React, Three.js, and Tailwind CSS.

## Features
- **Interactive Track Drawer**: Draw any circuit in freehand or point-to-point spline mode.
- **Dynamic 3D Elevation**: Rolling hills, mountain climbs, bridge overpasses, and cambered banks.
- **Arcade Physics**: Drifting mechanics, slip angle friction, tire smoke particles, skidmarks, and turbo boost.
- **Multiple Environments**: Pacific Coast, Neon Cyberpunk City, Desert Canyon, Alpine Snow Peak, and Sunset Speedway.
- **Audio Synthesizer**: Procedural Web Audio API engine rumble, turbo spool, tire screech, and crash sounds (no external audio files required).
- **Responsive Controls**: Keyboard arrow/WASD controls + mobile on-screen touch steering and pedals.

## Getting Started

### Local Development
```bash
npm install
npm run dev
```

### Build for Production / Web Cast
```bash
npm run build
```

## How to Deploy / Cast on Lovable
1. Upload this repository or drag-and-drop the project folder / `.zip` file into [Lovable](https://lovable.dev).
2. Lovable will automatically detect the Vite + React + TypeScript configuration and start the app.
3. No environment variables or server dependencies are required!
